# Code of Conduct

## The short version

Be respectful. Argue about code, not people. Harassment, personal attacks, and trolling aren't welcome here.

## What that means

This project runs on technical discussion. Disagreement about approach, pushback on a design, and blunt code review are all normal and expected. Keep it about the work.

These behaviors are not acceptable in any project space (issues, PRs, discussions):

- Harassment, insults, or personal attacks
- Publishing someone else's private information without consent
- Sustained disruption of discussion (trolling, derailing threads)
- Discriminatory language, sexual content, or threats of violence

## Enforcement

Maintainers can remove comments, close issues/PRs, or block contributors who violate this. Report a problem privately via a [GitHub security advisory](https://github.com/pturch/AutoMancer/security/advisories/new) or by contacting [@pturch](https://github.com/pturch) directly. Reports are handled confidentially.
