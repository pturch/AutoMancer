# Security Policy

## Supported Versions

AutoMancer is pre-1.0 and under active development. Only the latest code on `main` is supported — there are no maintained release branches yet.

## Reporting a Vulnerability

Please don't open a public issue for security vulnerabilities. Instead:

- Open a private [GitHub security advisory](https://github.com/pturch/AutoMancer/security/advisories/new), or
- Contact [@pturch](https://github.com/pturch) directly.

Include what you found, how to reproduce it, and its potential impact. You'll get a response and, if the report is valid, credit in the fix once it ships.
